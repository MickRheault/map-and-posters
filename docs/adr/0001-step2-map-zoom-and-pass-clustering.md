# Hysteresis Pass Clustering and SVG ViewBox Zoom/Pan on Step 2 Split Map

Both the Guided Wizard Step 2 split map (`src/wizard.ts`) and the Full Editor boundary editor (`src/itinerary-ui.ts`) now delegate map-click pass detection to a single pure helper `pickBoundaryPasses` in `src/itinerary.ts`, replacing duplicated per-point local-minimum loops that fragmented GPS jitter and switchback wiggles into noisy `Pass 1..5` micro-increments. `pickBoundaryPasses` uses screen-scaled hysteresis (`hitMargin = 3 / zoom`, `leaveMargin = 12 / zoom` in base `400 × 200` SVG units): consecutive samples near a click merge into one Pass represented by the closest sample, and a new Pass opens only after the route leaves `best + leaveMargin` and returns within `best + hitMargin`—collapsing same-visit noise without imposing a fixed kilometer cutoff that would break genuine short out-and-backs or small-scale tracks, while letting zoomed-in users intentionally resolve finer features. Step 2 zoom and pan are implemented directly over the SVG `viewBox` using pure clamped viewport helpers (`clampMapView`, `zoomMapView`, `panMapView`, `clientToMapPoint`) with zoom-compensated stroke/marker sizing, wheel-to-cursor zoom, `+`/`-`/`Reset` buttons, and 5 px drag-vs-click pointer disambiguation rather than CSS transforms or a third-party map library, preserving the standalone zero-dependency offline single-file HTML build, full JSDOM testability without `getScreenCTM`, and unchanged `Project` backup schema v1.
