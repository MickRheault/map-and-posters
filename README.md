# Map & Posters

Open `index.html` in a desktop browser, choose a GPX recording, edit the title, and download the 1080 × 1350 JPG. All processing happens on your computer. The poster draws recorded track segments and their elevation samples.

After changing the TypeScript or HTML in `src/`, run `bun build.ts` to rebuild the standalone editor. Run `bun test` for the geometry checks.
